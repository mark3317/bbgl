Автоматический режим предпочитает единственный активный VPN; при нескольких VPN
или нескольких обычных адаптерах требует выбора. VPN определяется по имени и
описанию адаптера. Перечисляются Up-адаптеры с Preferred IPv4 без loopback/APIPA.
Один IP заполняется автоматически, несколько доступны в списке, «Свой IPv4-адрес»
разрешает ручной ввод. Выбор сохраняется; отключённый выбранный адаптер не заменяется
молча. Работающий сервер фиксирует адрес до остановки.

Запуск сервера и настройка брандмауэра оставляют надпись «Играть»; кнопка временно
недоступна. Только подготовка игры показывает «Отменить».

Хост регистрируется и играет через 127.0.0.1. Новый необязательный параметр
сервера --local-shadnet задаёт локальные summon URL; гостям остаются URL выбранного
адреса. Правка внесена в standalone и bundled исходники сервера.
Скрипт ручной настройки брандмауэра использует подсети выбранного адаптера;
для своего адреса разрешает серверные порты со всех сетей, что указано в диалоге.
