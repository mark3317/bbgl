# 04.11.2026 — список и сетевой обмен файловыми модами

Статус: исходники и изолированные проверки готовы. Сборка, установка и обмен
между физическими ПК пока не выполнялись; игрового подтверждения нет.

В «Моды и читы → Установленные моды» список с переключателями и компактным
порядком загрузки. Длинные названия переносятся. Настройки путей вынесены в
«Папки модов». Каждые 3 секунды автоматически перечитываются папки и mods.json,
включая изменения выбора из игрового меню. Кнопка ручной проверки удалена.

bbport_mod_share.py обменивается каталогом и ZIP по существующему TCP discovery
37601 на выбранном интерфейсе кооператива. Новых портов/правил firewall нет.
Выбранная LAN/VPN остаётся границей доверия, как в Party discovery. Совместимым
участникам нужны обновлённые лаунчеры, работающие одновременно. Прежние клиенты
без поддержки обмена не мешают игровому обнаружению.

Каталог содержит имена, SHA256 содержимого, размеры и порядок/выбор модов;
хеширование и передача идут вне потока Qt. Хеши кешируются по метаданным файлов.
Файлы в исходной игре не читаются для упаковки и не изменяются. Передаются
папки установленных файловых модов, а не native DLL кооператива и не XML-патчи.

«Скачать мод» получает недостающую папку и оставляет её выключенной.
«Применить набор этого игрока» сначала проверяет все конфликты, скачивает
недостающие моды, затем применяет порядок/выбор игрока и включает загрузку модов.
Лишние местные моды сохраняются выключенными. Одноимённые разные версии не
перезаписываются; переключения, запуск и изменения папки заблокированы на время
скачивания. При ошибке новые полностью скачанные моды остаются выключенными,
старый порядок/выбор сохраняется. Повторное скачивание не перезаписывает папки.

Загрузка: временная скрытая папка, ограничение 8 ГБ/50000 файлов, проверка ZIP,
путей Windows, ссылок, повторов без учёта регистра и итогового содержимого;
публикация переименованием только после проверки. Скрытые staging-папки теперь
исключены из scripts/mods.discover, в том числе для других профилей лаунчера.
Сбой/обрыв удаляет текущую временную загрузку. Внезапное завершение процесса
может оставить скрытую временную папку, которую загрузчик модов игнорирует.
