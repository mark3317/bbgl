# Чёрный экран после подготовки шейдеров — 04.11.2026

Пользователь видит примерно секунду серого экрана после подготовки шейдеров.
Ранее Presenter сразу скрывал индикатор по возврату из WarmUp.

После фактически показанной подготовки Presenter сохраняет индикатор на 100%
ещё на 1500 мс с первого нового игрового кадра. Подготовительные и повторные
кадры не запускают и не продлевают отсчёт. Нулевой размер окна также не запускает
отсчёт. Без показанной подготовки дополнительной задержки нет.
Экран индикатора теперь имеет непрозрачную чёрную подложку поверх игры,
поэтому продолжающийся запуск скрыт на время задержки. Потоки игры не блокируются.

Это ограниченная задержка, а не анализ пикселей или сигнал готовности меню:
при более долгом сером участке потребуется настройка по игровому наблюдению.

Проверка: целевая сборка bb-probe через MSYS2 CLANG64 завершилась exit=0;
git diff --check затронутых файлов PASS. Тесты извлечения/каталога шейдеров
не запускались: их поведение не изменено.
Установка и игровой визуальный контроль не выполнены. Сейвы, настройки,
игровые файлы и BBSC/pin не менялись.
