# 04.11.2026 — серебряный игровой курсор (вариант 1)

Пользователь выбрал первый вариант из листа ImageGen: потёртое серебро,
тёмный контур и небольшая насечка у основания. Прозрачный оригинал, превью,
описание происхождения и точный запрос: `assets/cursors/`.

Курсор встроен в порт как SDL color cursor: 32×48 и 64×96 для высокого DPI,
hotspot (1,1) на острие. Владение ресурсом — WindowSDL; при закрытии окна
восстанавливается стандартный SDL cursor, затем ресурс освобождается.
При ошибке создания остаётся системная стрелка с сообщением в лог.

Нативные меню, дополнительное меню и Атлас используют одну стрелку.
Программная стрелка ImGui отключена во избежание двойного отображения.
Существующие правила захвата мыши, скрытия курсора, контроллера и кликов
не изменены. Системные курсоры Windows вне игры не меняются.

Проверка `tests/test_silver_cursor.cpp` PASS: размеры обоих RGBA изображений,
прозрачный отступ, непрозрачное остриё/hotspot, двукратный реальный SDL цикл
create/set/destroy на скрытом окне. Vulkan, игра и профили не используются.
`git diff --check` для изменённых файлов — PASS.

Сборка и установка: ожидаются. Игровой визуальный контроль не выполнен.
Установка должна включать только `bin/bb-probe.exe`, без параллельных изменений
лаунчера/Party, для которых в другом чате пользователь просил пока не устанавливать.
