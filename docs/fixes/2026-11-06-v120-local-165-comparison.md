## Память: различать committed и working set

Пользователь отметил одинаковое распределение памяти. Private committed
действительно близок: ~5.6–5.9GiB на процесс в обоих прогонах.
На новой сборке guest working set в минутных Memory reports вырос
3605→12986→13052MiB, host3595→3677→3696MiB.
На1.2.0 guest3791→3744MiB, host3746→3702MiB; снимок процессов это подтверждает.
Рабочий набор включает shared/mapped pages: это НЕ доказательство private heap leak.
Сильный рост RAM-residency гостя в текущем интервале1.2.0 не воспроизвёлся.

На1.2.0 нет BBSC perf scopes в native логе, несмотря на те же настройки
PERF; нельзя выдавать отсутствие строк за нулевое время обработчиков.
В обоих прогонах relay queue0/dropped0. Обычный режим NPC, не native-sync TEST.
