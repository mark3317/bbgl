# BBGL 1.4.2

This release bundles [BBSC-GL 1.4.1](https://github.com/mark3317/bbsc-gl/releases/tag/v1.4.1) and Party. If a guest is still joining, the game waits before selecting another summon sign. Signs already received remain available for the next summon after the current admission finishes or is cancelled.

### Install or update

Close the game and launcher, extract `bbgl-1.4.2-windows-x64.zip` and run **Bloodborne.exe**. Keep your existing profile, saves and custom mods. Use Windows x64, a Vulkan-capable driver and your Bloodborne **CUSA03173 with update 1.09**. All co-op players should use BBGL 1.4.2 on the same LAN or VPN.

### Checks

Bench checks covered 325 combinations of host, roster and join order for one to five players, plus a five-client run covering sequential joins, cancellation, capacity and rejoining. Live gameplay with this build remains unverified.

## Русский

В выпуск входит [BBSC-GL 1.4.1](https://github.com/mark3317/bbsc-gl/releases/tag/v1.4.1) с Party. Пока гость подключается, игра ждёт перед выбором следующего знака. Уже полученные знаки сохраняются и снова доступны после завершения или отмены текущей заявки.

### Установка и обновление

Закройте игру и лаунчер, распакуйте `bbgl-1.4.2-windows-x64.zip` и запустите **Bloodborne.exe**. Сохраните существующий профиль, сохранения и пользовательские моды. Нужны Windows x64, драйвер Vulkan и Bloodborne **CUSA03173 с обновлением 1.09**. Для кооператива используйте BBGL 1.4.2 на всех ПК и общую локальную сеть или VPN.

### Проверки

На стенде проверены 325 сочетаний хоста, состава и порядка входа для 1–5 игроков. Пять клиентов прошли последовательный вход, отмену заявки, заполнение комнаты и повторное подключение. Проверка этой сборки в игре ещё предстоит.
