# BBGL 1.4.2

This release bundles [BBSC-GL 1.4.1](https://github.com/mark3317/bbsc-gl/releases/tag/v1.4.1) and Party.

- The game waits for the current guest to join or for the invitation to be cancelled before selecting the next summon sign. It keeps signs it has already received.
- During a boss fight, fallen players spectate while a teammate is alive. After the whole team falls, each player loads back at the last shared lamp in the same session. One player's early return no longer interrupts the others' reloads.
- On a boss retry, the guest's fog gate is restored and the guest can enter after the host. The change covers 25 boss entry events across the base game, DLC and Chalice Dungeons.

### Install or update

Close the game and launcher, extract `bbgl-1.4.2-windows-x64.zip` and run **Bloodborne.exe**. Keep your existing profile, saves and custom mods. Use Windows x64, a Vulkan-capable driver and your Bloodborne **CUSA03173 with update 1.09**. All co-op players should use BBGL 1.4.2 on the same LAN or VPN.

### Checks

Bench checks covered 325 combinations of host, roster and join order for one to five players, all six return orders for three players after a team wipe, and 25 original boss entry events. Live gameplay with this build remains unverified.

## Русский

В выпуск входит [BBSC-GL 1.4.1](https://github.com/mark3317/bbsc-gl/releases/tag/v1.4.1) с Party.

- Игра сохраняет полученные знаки и ждёт входа текущего гостя или отмены приглашения перед следующим призывом.
- В бою с боссом погибшие наблюдают, пока жив хотя бы один напарник. После гибели всей команды каждый игрок загружается у последней общей лампы в той же сессии. Возвращение первого игрока больше не прерывает загрузку остальных.
- При повторной попытке у гостя восстанавливается туман босса, а проход становится доступен после хоста. Изменение охватывает 25 событий входа в основной игре, дополнении и подземельях чаш.

### Установка и обновление

Закройте игру и лаунчер, распакуйте `bbgl-1.4.2-windows-x64.zip` и запустите **Bloodborne.exe**. Сохраните существующий профиль, сохранения и пользовательские моды. Нужны Windows x64, драйвер Vulkan и Bloodborne **CUSA03173 с обновлением 1.09**. Для кооператива используйте BBGL 1.4.2 на всех ПК и общую локальную сеть или VPN.

### Проверки

На стенде проверены 325 сочетаний хоста, состава и порядка входа для 1–5 игроков, все шесть порядков возвращения троих игроков после гибели команды и 25 оригинальных событий входа на босса. Проверка этой сборки в игре ещё предстоит.
