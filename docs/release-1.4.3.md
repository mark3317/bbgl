# BBGL 1.4.3

Includes [BBSC-GL 1.4.2](https://github.com/mark3317/bbsc-gl/releases/tag/v1.4.2) and Party.

- **Mensis elevators.** All six elevators restore their position when a player loads the map. The original game scripts control movement and lever state during play.
- **Boss retries.** The host and guests use the original role checks at the fog gate. This covers 25 boss entry events in the base game, DLC and Chalice Dungeons.
- **Party reunion.** When a settled player task has no character after a transition, the game gets one request to recreate that teammate.
- **Guest return and DLC gift.** An aborted return keeps the existing recovery path available. The Hunter's Dream preserves each player's receipt for the Eye of a Blood-drunk Hunter and restores a missing receipt for a guest who already owns the item.

### Install or update

Close the game and launcher, extract `bbgl-1.4.3-windows-x64.zip` and run **Bloodborne.exe**. Keep your profile, saves and custom mods. Use Windows x64, a Vulkan-capable driver and your copy of **Bloodborne CUSA03173 with update 1.09**. Use BBGL 1.4.3 on every PC on the same LAN or VPN.

### Checks

Targeted checks covered the original elevator and fog events, party reunion, guest return and the personal DLC gift. This build awaits a live co-op run. The reported repeat summon failures and timing differences in enemy loot processing are still under investigation.

## Русский

В комплекте [BBSC-GL 1.4.2](https://github.com/mark3317/bbsc-gl/releases/tag/v1.4.2) и Party.

- **Лифты Менсиса.** Все шесть лифтов восстанавливают положение при загрузке карты. Во время игры движением и рычагами управляют штатные скрипты.
- **Повторный вход к боссу.** У тумана действуют штатные проверки роли хозяина и гостя. Правка охватывает 25 событий в основной игре, дополнении и подземельях чаш.
- **Воссоединение группы.** Если после перехода задача напарника готова, а персонажа нет, игра получает один запрос на его создание.
- **Возврат гостя и подарок DLC.** Если штатный переход домой прервался, остаётся доступен резервный возврат. Сон охотника сохраняет личный флаг предмета «Глаз напившегося крови охотника» и восстанавливает его у гостя, который уже получил предмет.

### Установка и обновление

Закройте игру и лаунчер, распакуйте `bbgl-1.4.3-windows-x64.zip` и запустите **Bloodborne.exe**. Сохраните профиль, сохранения и пользовательские моды. Нужны Windows x64, драйвер с Vulkan и **Bloodborne CUSA03173 с обновлением 1.09**. Для кооператива установите BBGL 1.4.3 на всех ПК и подключитесь к одной локальной сети или VPN.

### Проверки

На стенде проверены оригинальные события лифтов и тумана, создание напарника, возврат гостя и личный подарок DLC. Игровой прогон этой сборки ещё впереди. Причины двух отказов повторного призыва и расхождений по времени обработки добычи остаются открытыми.
