## Русский

- Гости могут первыми пройти через уже появившийся туман босса. У Людвига при повторном заходе туман восстанавливается и в одиночной игре. Расширенный журнал показывает состояние арены при её загрузке.
- После общей гибели в Менсисе сбрасываются временные флаги фаз и маршрутов Миколаша.
- Если гостевой запрос не проходит напрямую, Party использует уже открытое соединение хоста. При сорвавшемся призыве освобождаются резерв и зовущий колокол гостя.

Закройте игру и лаунчер, распакуйте Windows ZIP и запустите **Bloodborne.exe**. Требуется Bloodborne CUSA03173 с обновлением 1.09. Обновите всех участников группы до одной версии. [Отдельный релиз BBSC-GL 1.5.4](https://github.com/mark3317/bbsc-gl/releases/tag/v1.5.4).

## English

- Guests can enter an existing boss fog gate before the host starts the fight. Ludwig's fog is restored on retries in solo play too. Extended logs record arena state when it loads.
- A group wipe in the Nightmare of Mensis resets Micolash's temporary phase and route flags.
- Party can use the host's existing connection when a guest request fails on the direct path. A failed summon clears the guest's reservation and releases the Beckoning Bell.

Close the game and launcher, extract the Windows ZIP, and run **Bloodborne.exe**. Requires Bloodborne CUSA03173 with update 1.09. Update every player to the same version. [Standalone BBSC-GL 1.5.4](https://github.com/mark3317/bbsc-gl/releases/tag/v1.5.4).
