# BBGL 1.5.5

## Русский

В Менсисе снимок мира задаёт положение лифта в Бездну до запуска событий карты. После загрузки положением управляет штатное событие лифта. Проверки на стенде прошли. Игровой прогон остаётся открытым.

Включён [BBSC-GL 1.5.5](https://github.com/mark3317/bbsc-gl/releases/tag/v1.5.5). Распакуйте Windows ZIP и запустите `Bloodborne.exe`. Для совместной игры обновитесь до одной версии.

## English

In Nightmare of Mensis, the world snapshot sets the Abyss lift position before map events start. After loading, the original lift event controls its position. The targeted checks passed. An in-game test is still pending.

Includes [BBSC-GL 1.5.5](https://github.com/mark3317/bbsc-gl/releases/tag/v1.5.5). Extract the Windows ZIP and run `Bloodborne.exe`. Keep everyone in the co-op group on the same version.
