# BBGL 1.5.9

## Русский

- Включён BBSC-GL 1.5.9 с исправлениями согласования общей гибели на боссе. Погибшие ждут статусы известных участников, а смена присутствия или состава запускает повторную проверку.
- Сообщения о смерти из предыдущего визита больше не подтверждают готовность к загрузке в текущем визите.

Распакуйте Windows ZIP и запустите `Bloodborne.exe`. Для согласованного возрождения обновите всех участников до 1.5.9. Четыре сценария прошли на стенде. Проверка в игре остаётся открытой.

## English

- Includes BBSC-GL 1.5.9 with fixes for coordinated boss-death recovery. Dead players wait for known teammates, and changes in presence or party size trigger a readiness check.
- A death message from an earlier visit cannot mark a player ready in the current visit.

Extract the Windows ZIP and run `Bloodborne.exe`. Update everyone to 1.5.9 for coordinated recovery. All four regression cases passed. In-game verification is pending.
