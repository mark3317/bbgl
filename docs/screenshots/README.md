# Скриншоты BBGL 1.4.3

Сняты 08.11.2026 из текущего QML-интерфейса. Для обновления:

```powershell
out/qt-venv/Scripts/python.exe tools/capture_release_screenshots.py
```

Скрипт снимает главный экран в совместном режиме и настройки изображения.
Он использует временный профиль без доступа к игре и сетевого обнаружения.
На главном экране показан пример профиля Hunter до выбора папки игры.
