# Скриншоты BBGL 1.6.1

Сняты 17.11.2026 из текущего QML-интерфейса. Для обновления:

```powershell
out/qt-venv/Scripts/python.exe tools/capture_release_screenshots.py --output out/screenshots
out/qt-venv/Scripts/python.exe tools/capture_release_screenshots.py --language en --review --output out/release-review/en
```

Первый вызов снимает главный экран в совместном режиме. Для вкладки «Эффекты
изображения» используется `launcher-section-0-1-1290.png` из второго вызова.
Он использует временный профиль без доступа к игре и сетевого обнаружения.
На главном экране показан пример профиля Hunter до выбора папки игры.
