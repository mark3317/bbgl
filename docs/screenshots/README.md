Сняты 05.11.2026 из текущего QML-интерфейса. Для обновления:


Используется временный профиль без доступа к игре и сетевого обнаружения.
Имя Hunter и пути C:/Games/BBGL — примеры; установленный мод Diamond Sword
показан выключенным, как в новом релизном профиле. Главный экран честно
показывает состояние до выбора игры. Это снимки интерфейса, не подтверждение
подключения или игрового результата. После генерации проверить PNG глазами.
